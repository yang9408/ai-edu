# 知识库索引（Sprint 1）

## 技术主题

- 案例拆解：如何从教学案例抽取“可复用骨架”
- 迭代方法：如何做最小可验证改动（MVP-first）
- 文档工程：如何保证一周后仍可读、可接续

## 方法论（固定结构）

### 学习方法

- 输入：只选“当前目标直接相关”的资料
- 处理：每次学习必须产出结构化笔记
- 输出：把笔记转换为项目动作（Issue / TODO / Patch）

### 项目方法

- 先跑通，再优化
- 每次只改一个层面（功能 / 结构 / 文档）
- 每次迭代都要有可见产物

### 复盘模板

- 本周目标是否完成？
- 最大收益动作是什么？
- 最大浪费动作是什么？
- 下周停止做什么？开始做什么？继续做什么？
